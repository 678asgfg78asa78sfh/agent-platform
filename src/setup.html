⚡ Agent Platform — Setup

Language:

Welcome! To build your first agent you need an LLM backend. Pick an option below, test it, save — takes about 30 seconds. After that the AI Wizard is ready and you create agents by talking to it.

This protects the Agent Platform admin API over LAN. It is not your LLM API key.

🌐 OpenRouter

FREE · many models
OpenRouter is an LLM aggregator with dozens of models (GPT, Claude, Gemini, DeepSeek, Qwen, Grok, Kimi) behind one API. Free models available (e.g. deepseek/deepseek-chat:free, qwen/qwen3-coder:free), paid flagship models on demand. Get an API key at openrouter.ai/keys (email only, no card required for free tier).

NVIDIA NIM

NVIDIA · OpenAI-compatible
NVIDIA hosted OpenAI-compatible API. Uses https://integrate.api.nvidia.com/v1; get a key from NVIDIA API Catalog.

DeepSeek

PAID · direct API
Direct DeepSeek API with native thinking controls. Uses https://api.deepseek.com; get a key at platform.deepseek.com.

🦙 Ollama (local/LAN)

FREE · local/LAN
If ollama serve runs locally or on your LAN: zero cloud. Pull a model first: ollama pull llama3.2. See ollama.com.

🤖 OpenAI

PAID · GPT-5.x
Standard OpenAI API. Get a key at platform.openai.com/api-keys.

🧠 Anthropic (Claude)

PAID · Claude 4.x
Direct Anthropic API. Get a key at console.anthropic.com.

🤖 Claude Code (claude -p)

ABO · lokal
Lokale Claude Code CLI als reiner Text-LLM. Nutzt dein bestehendes Claude-Abo (kein API-Key, kein Per-Call-Cost). Voraussetzung: claude ist installiert & eingeloggt.

🐫 llama.cpp server

LOCAL · OpenAI-compatible
Enter the network URL of your llama-server or any OpenAI-compatible LAN server, for example http://192.168.200.18:8080.
Advanced users can edit agent-data/config.json directly — see docs/templates/. After setup you land on / (admin UI) and can start the AI Wizard.
